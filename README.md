# Сайт «Эхо» (echo-site)

Лендинг бота @EchoSave_bot. Отдельное **открытое** хранилище: здесь только страницы сайта, кода бота и
секретов нет. Правила сайта — `docs/RULES.md` в echo-bot, раздел 2, «Сайт (лендинг)».

Сейчас готов русский (`/ru/`). Места под английский (`/en/`) и хинди (`/hi/`) заложены: в переключателе
языков они серые, пока страниц нет.

## Где лежит

Организация GitHub **EchoSavebot**, хранилище `EchoSavebot/echosavebot.github.io` (открытое), сайт —
**https://echosavebot.github.io/** (опубликован 10.10.2026). Настройки — Settings → Pages: ветка `main`, папка `/ (root)`.

Чтобы обновлять из GitHub Desktop: **File → Clone repository** → `EchoSavebot/echosavebot.github.io` →
папка `C:\git\echosavebot.github.io` (отдельно от `C:\git\echo-bot`).

## Свой домен

1. Купите домен (например, на Porkbun или Namecheap). Слово «Telegram» в названии брать нельзя.
2. Сообщите Claude название — он пересоберёт сайт с новым адресом и пришлёт точные записи для настройки.
3. В общих чертах: у продавца домена в DNS добавляются четыре записи `A` на адреса GitHub
   (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) и `CNAME` для `www` →
   `echosavebot.github.io`; затем на GitHub в **Settings → Pages → Custom domain** вписывается домен и включается
   **Enforce HTTPS**.

## Как обновлять

Claude присылает новый `echo-site.zip` → содержимое папки `echo-site` из архива скопируйте в `C:\git\echosavebot.github.io` **с заменой файлов** → GitHub Desktop →
**Commit to main** (текст коммита — от Claude) → **Push origin**. Через минуту изменения на сайте.

## Для разработчика

- Все тексты — в `src/texts/<язык>.json`, страницы собирает `src/build.py` (нужен Python 3 и Pillow):
  `python src/build.py` из корня хранилища. Собранные страницы лежат в хранилище — GitHub Pages ничего не собирает.
- Адрес сайта, ссылки на бота, поддержку, политику и правила, список языков — вверху `src/build.py`.
- Новый язык: скопировать `src/texts/ru.json` в `<код>.json`, перевести значения, в `LANGS` поставить `True`,
  пересобрать. Главная страница сама выбирает готовый язык по настройкам браузера, иначе — русский.
- Цвета — из аватарки бота (#8C6FFF → #51BEFF), `assets/style.css`. Шрифты системные: кириллица и
  деванагари есть на всех телефонах и ПК.
- Без cookies, счётчиков, чужих скриптов и шрифтов. Счётчик посещений — только после правки политики.
