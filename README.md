# Сайт «Эхо» (echo-site)

Лендинг бота @EchoSave_bot. Отдельное **открытое** хранилище: здесь только страницы сайта, кода бота и
секретов нет. Правила сайта — `docs/RULES.md` в echo-bot, раздел 2, «Сайт (лендинг)».

Сейчас готов только русский (`/ru/`). Места под английский (`/en/`) и хинди (`/hi/`) заложены в `LANGS`, но
на сайте не видны: неготовые языки не показываются, а при одном языке переключателя нет. Блок «Скоро — для Индии и
других стран» убран (решение владельца 14.10.2026): вернётся вместе с версией для других стран.

## Что на странице (14.10.2026)

- Срок хранения (48 часов) на сайте не называется — только в «Условиях и конфиденциальности» (решение владельца
  14.10.2026, как в боте и в @BotFather). В «Ваших данных» — «Стирается само» без числа.
- «📜 Переписка файлом»: четвёртая карточка в «Что умеет», пункт «Переписка» в меню сайта, свой блок `#perepiska`
  с телефоном, который сам показывает историю (Алина удалила чат → Меню → «📜 Переписка» → файл → файл открыт;
  без JavaScript — сразу открытый файл), вопрос в FAQ и раздел в «Подробнее». Все люди и сообщения в примерах
  вымышленные.
- Время в примерах — «МСК», как в боте.

## Где лежит

Организация GitHub **EchoSavebot**, хранилище `EchoSavebot/echosavebot.github.io` (открытое), сайт —
**https://echosave.online/** (опубликован 10.10.2026 на echosavebot.github.io, свой домен — 11.10.2026,
куплен на Porkbun; продление около 29 $ в год). Настройки — Settings → Pages: ветка `main`, папка `/ (root)`.

Чтобы обновлять из GitHub Desktop: **File → Clone repository** → `EchoSavebot/echosavebot.github.io` →
папка `C:\git\echosavebot.github.io` (отдельно от `C:\git\echo-bot`).

## Счётчик посещений (Umami, без cookies)

1. Зарегистрируйтесь на https://cloud.umami.is (бесплатный тариф Hobby).
2. **Settings → Websites → Add website**: Name — `Эхо`, Domain — `echosave.online` → Save.
3. Откройте сайт в списке → **Edit** → скопируйте **Website ID** (строка вида `xxxxxxxx-xxxx-…`) и пришлите Claude.
4. Claude впишет его в `UMAMI_ID` (вверху `src/build.py`) и пересоберёт сайт; строка внизу сайта сама сменится на
   «Сайт считает посещения через Umami — без cookies и без личных данных».

Кнопки «Открыть бота» считаются как событие `open-bot` с местом (`header`, `hero`, `connect`, `final`).

## Свой домен

1. Купите домен (например, на Porkbun или Namecheap). Слово «Telegram» в названии брать нельзя.
2. Сообщите Claude название — он пересоберёт сайт с новым адресом и пришлёт точные записи для настройки.
3. В общих чертах: у продавца домена в DNS добавляются четыре записи `A` на адреса GitHub
   (185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153) и `CNAME` для `www` →
   `echosavebot.github.io`; затем на GitHub в **Settings → Pages → Custom domain** вписывается домен и включается
   **Enforce HTTPS**.

## Как обновлять

Claude присылает новый `echo-site.zip` → содержимое папки `echo-site` из архива скопируйте в `C:\git\echosavebot.github.io` **с заменой файлов** → GitHub Desktop →
**Commit to main** (текст коммита — от Claude) → **Push origin**. Через минуту изменения на сайте.

## Для разработчика

- Все тексты — в `src/texts/<язык>.json`, страницы собирает `src/build.py` (нужен Python 3 и Pillow):
  `python src/build.py` из корня хранилища. Собранные страницы лежат в хранилище — GitHub Pages ничего не собирает.
- Адрес сайта, ссылки на бота, поддержку, документ «Условия и конфиденциальность», список языков — вверху `src/build.py`.
- Новый язык: скопировать `src/texts/ru.json` в `<код>.json`, перевести значения, в `LANGS` поставить `True`,
  пересобрать. Главная страница сама выбирает готовый язык по настройкам браузера, иначе — русский.
- Цвета — из аватарки бота (#8C6FFF → #51BEFF), `assets/style.css`. Шрифты системные: кириллица и
  деванагари есть на всех телефонах и ПК.
- Без cookies, счётчиков, чужих скриптов и шрифтов. Счётчик посещений — только после правки политики.
